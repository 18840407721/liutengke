使用说明

1. App ID / App Secret 在哪里获取？

  1. 打开飞书开放平台 open.feishu.cn，进入「开发者后台」。
  2. 创建「企业自建应用」（或选择已有的自建应用），进入该应用。
  3. 左侧「凭证与基础信息」页面即可看到 App ID 和 App Secret。
App ID形如 cli_xxxxxxxxxxx
App Secret形如一段长随机字符串

2. 还需要开通哪些权限？

  1. 在应用「权限管理」中搜索并添加多维表格相关权限，至少需要：
    • bitable:app（查看多维表格）
    • bitable:app:readonly 或写入相关权限（如需回写记录）
  2. 在「版本管理与发布」中创建版本并发布，需由企业管理员审核通过后，应用才能实际调用接口。

3. app_token 在哪里获取？

打开目标多维表格，地址栏 URL 形如：

https://xxx.feishu.cn/base/xxxxxxxxxxxxxxxxxxxxxxxxxx?table=tblxxxx&view=vewxxxx

其中 /base/ 后面、第一个 ? 之前的字符串，就是 app_token（约 26 位）。

!
注意：如果 URL 路径是 /wiki/，则需要先通过「开发工具」插件或把文档加入多维表格后，再复制 /base/ 形式的链接获取 app_token。

4. table_id 在哪里获取？

同一 URL 中，?table= 参数对应的值就是当前数据表的 table_id：

.../base/xxxxxx?table=tblxxxxxxxxxxxxxxxxx&view=vewxxxx

5. 翻译引擎

本插件使用 MyMemory 免费直连接口（无需 API Key），接口：

https://api.mymemory.translated.net/get?q={text}&langpair={source}|{target}

免费接口存在每日字符限额与并发限制，建议边栏翻译文本不要过长，字段翻译时降低并发数（默认 2）。

6. 权限与数据安全提示

  • App Secret 属于敏感凭据，请勿公开传播；本插件仅将其保存在你当前的浏览器本地。
  • 字段翻译会在翻译完成后回写原字段，属于修改操作，翻译前建议先备份多维表格或使用「仅预览」模式核对。
  • 除翻译引擎与飞书接口外，本插件不会向任何第三方发送表格数据。
